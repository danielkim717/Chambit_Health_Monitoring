# 측정 기능 검증 기록

## 2026-09-14 · 프레임 수집 병목 수정

- 사용자 화면에서는 얼굴 ROI가 표시됐으나 60초 후 심박·호흡 모두 영상 속도 부족으로 거부됐습니다.
  당시 실제 fps·처리 시간은 확보되지 않아 특정 장치나 촬영 환경이 원인이라고 단정하지 않습니다.
- 카메라의 최대 30fps 요청 뒤 프레임 간격을 중복 제한하던 로직을 제거했습니다. 얼굴 처리 중에는
  최신 실제 프레임 하나만 대기시켜 처리 완료 즉시 전달합니다. 이전 대기 프레임은 해제하고,
  촬영 시각·중복 프레임 거부·취소 및 구간 변경 처리를 유지합니다.
- 화면 상태 갱신은 최대 약 4회/초, ROI 테두리는 최대 약 10회/초로 줄였습니다.
  모델 출력이 캐시된 과거 구간은 다시 축소하지 않고 새 입력 구간만 전처리합니다.
- `capture` 진단에 브라우저 영상 표시 fps, 콜백 fps, 얼굴 처리 fps·시간, 대기 교체,
  얼굴 조건 거부, 전송 누락을 구분했습니다. 속도 부족 안내는 측정 도중에도 표시합니다.
  클라이언트 진단은 설명용이며 서버의 실제 시각 기반 입력 검증을 우회하지 않습니다.
- Python 48개·Node 35개 통과. 30fps 입력과 38ms 처리 시간을 가정한 모의 실행에서 24fps 이상
  전달, 촬영 시각 유지, 대기 프레임 해제, 취소 후 늦은 비트맵 폐기를 확인했습니다.
  36초 캐시 뒤 38초 분석에서 전체 1,141프레임 대신 새 구간 64프레임 이하만 축소했습니다.
- 브라우저 전체 검사 15개 통과, Edge 가상 카메라 연결 종료 1개 실패(단독 재실행도 실패).
  별도 Edge 확인에서는 최대 30fps 설정으로 실제 Worker가 동작했으며 가상 장치의 영상 속도는
  20fps였습니다. 가상 장치 종료는 두 요청 설정에서 관찰돼 검사의 불안정성을 별도로 남깁니다.
  이는 실제 사용자의 카메라 성능이나 수정 후 측정 성공을 입증한 결과가 아닙니다.
- 속도 안내·진행 막대·재측정 초기화의 후속 Chrome·Edge 검사 2개는 통과했습니다.

## 2026-09-14 · 실패 안내와 측정 타임라인

- 영상 수신 속도 부족·프레임 공백·약한 신호·분석 기능 준비 실패를 원인별로 구분합니다.
  사용자 안내에서 모델 이름·fps 임계값을 제거하고, 원문과 실제 수치는 접힌 개발용 상세 정보에 유지합니다.
- 수집 시간으로 움직이는 상단 진행 막대에 심박 20초·호흡 35초·수집 완료 60초를 표시합니다.
  재준비 시 막대를 초기화하고, 시작 시점 도달과 유효한 수치 산출을 구분합니다.
- 중간 분석을 심박 30→20초, 호흡 45→35초로 앞당겼습니다. 기존 파형 분석의 최소 구간과
  품질 조건은 유지하며, 초기 중간값의 정확도와 실제 대기 시간은 추가 실측이 필요합니다.
  준비 5초·수집 60초·실패 시 가상 수치로 대체하지 않는 동작은 동일합니다.
- Python 40개, Node 29개, Chrome·Edge 브라우저 16개 테스트 통과.
  합성 파형의 20초 심박·35초 호흡 출력, 요청 교체, 실패 원인 분리, 데모와 타임라인,
  부분 결과, 문진, 재측정 초기화 및 모바일 화면 배치를 확인했습니다.
  실제 웹캠의 호흡 측정 성공률이나 정확도를 검증한 결과는 아닙니다.

## 2026-09-12 · 호흡 분석 대기 상태와 갱신 수정

- 호흡 카드에 수집 45초까지 남은 시간, 분석 중, 신호 부족, 후보 불일치를 구분해 표시합니다.
- 호흡 갱신 주기를 실제 처리한 구간으로 계산합니다. 대기 중인 호흡 작업이 최신 심박 작업으로
  교체되어도 호흡 분석이 누락되지 않습니다. 재측정 시 이전 호흡 결과를 초기화합니다.
- 호흡 후보가 없을 때 MTTS-CAN 가중치 오류·입력 fps 조건·파형 품질 이유를 표시합니다.
- Python 테스트 38개 통과. 추가 검사는 합성 출력으로 호흡 단독 성공·갱신·입력 거부를
  검증하며 실제 사용자의 웹캠 호흡 측정 성공을 확인한 것은 아닙니다.
- Node 테스트 27개와 Chrome의 관련 브라우저 테스트 2개 통과. 브라우저 검사는 결과
  대역으로 45초 대기 안내·호흡 단독 표시·문진의 부분 결과 유지를 확인했습니다.

### 아직 수행하지 않은 검증

- 실제 사람이 있는 웹캠의 **연속 60초 전체 경로**와 동시 기준 HR·RR 비교.
- 성인 5명 이상, 각 3회 이상의 독립 측정. 안정 조건과 움직임·조명 변화 조건을 구분합니다.
  개발 목표: HR MAE ≤5bpm, RR MAE ≤3회/분, 안정 조건 유효 결과율 ≥80%.
  임계값을 조정한 기록과 최종 평가 기록을 분리합니다.
- 실제 사람 영상의 전체 동영상 전처리 대비 실시간 구간 전처리 비교.
  replay 도구는 준비되어 있으나 기준값이 있는 영상은 이 작업에 제공되지 않았습니다.
- 젯슨 기종·JetPack별 TensorRT FP16, 브라우저 포함 30분 메모리·발열·지연 시험.
- 실제 외부 LLM과 Qwen3-1.7B 로컬 서버의 한국어 응답 품질·속도.

후속 비교 CSV 형식은 participant,attempt,condition,reference_hr,hr,reference_rr,rr입니다.
측정 실패는 빈칸으로 기록하고 분모에 포함합니다. inference.evaluate로 MAE·RMSE·유효 결과율을 계산합니다.

## 자동 검증

- `npm.cmd test`: **23개 통과**, 합성 신호, 측정 상태, 정적 서버, 자산 체크섬 검증.
- `npm.cmd run test:browser`: **14개 통과** (Chrome 7개 + Edge 7개, 23.6초). 테스트 결과 `test-results/.last-run.json`의 상태는 `passed`이다.
- 합성 RGB 60초 입력: 심박 60·90·120bpm × 호흡 9·15·24회/분의 9조합에서 심박 오차 ≤3bpm, 호흡 오차 ≤2회/분을 확인한다.
- 별도 맥파 입력과 불규칙한 프레임 시각을 확인한다. 무신호·잡음·긴 공백·중복 시각·낮은 fps는 측정 불가, 호흡 변동 없는 맥파는 심박수만 반환한다.
- 5초 준비와 60초 수집, 0.5초 품질 저하 시 구간 폐기, 120초 만료, 중복 프레임 및 취소 후 이벤트를 확인한다.
- Chrome·Edge: 권한 거부, 실제 로컬 WASM/모델 초기화, 가상 카메라의 얼굴 없음, 모델 오류, 가상 시계로 65초 데모, 문진·결과·재측정, 페이지/탭 이동 취소, 부분 결과, 모바일/데스크톱 배치를 확인한다.
- 브라우저의 부분 결과·모델 실패 시나리오는 Worker 테스트 대역을 사용한다. 실제 모델 실행 테스트는 대역 없이 로컬 모델과 가상 카메라를 사용한다. 이 두 종류를 실제 사람의 측정 정확도로 해석하지 않는다.

## 실제 사람 비교 시험 — 미수행

사람의 웹캠 영상과 동시 기준 심박수·호흡수가 확보되지 않아 실제 사람 대상 정확도와 측정 성공률은 아직 산출하지 않았다. 아래 절차로 후속 검증한다.

1. 같은 카메라·브라우저를 사용해 편안한 앉은 자세와 고른 조명에서 측정한다. 브라우저·카메라·조명 조건을 기록한다.
2. 준비 5초를 제외한 **동일한 수집 60초** 동안 기준 기기의 평균 심박수와 관찰자가 센 호흡 횟수를 기록한다. 특정 시점의 기기 표시값을 60초 평균 대신 비교하지 않는다.
3. 독립된 측정을 최소 3회 진행하고 앱의 원래 결과를 그대로 기록한다. 측정 불가 시도도 성공률 분모에 포함한다. 반복된 중간 추정값을 독립 측정으로 세지 않는다.
4. 심박·호흡별 절대 오차와 평균 절대 오차, 유효 결과 수/전체 시도 수를 계산한다. 기준 장비의 종류·한계도 함께 적는다.
5. 움직임·조명 변화·낮은 fps 조건에서는 수치 정확도와 별도로 거부/재준비가 의도대로 일어나는지 확인한다. 서로 다른 피부색·얼굴 가림·카메라 조건에 대한 일반화는 이 소규모 시험만으로 주장하지 않는다.
